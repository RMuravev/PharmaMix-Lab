# Итерация 43 — HAC-инференция

## Что добавлено
- `calculateHacInference` связывает OLS point estimates с HAC/Newey–West covariance estimator.
- Возвращает HAC standard errors, t-statistics, приближённые confidence intervals и индикатор пересечения критического значения.
- При недостатке степеней свободы или вырожденной матрице выводы не маскируются числовыми значениями.
- p-value намеренно не выводится: здесь не реализовано точное маловыборочное распределение HAC-статистики.

## Ограничения
- Наблюдения должны быть упорядочены хронологически и равномерно расположены.
- Пропущенные периоды, панели (например, несколько регионов или брендов) и структурные разрывы нужно обработать отдельно.
- t-критические значения табличные; доверительные интервалы являются приближёнными.
- Сервис пока не подключён к текущему MMM UI/движку.
- `npm test` и `npm run build` необходимо запустить в окружении с установленными зависимостями.
