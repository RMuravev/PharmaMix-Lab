# Импорт промо-данных

`normalizePromoRows` приводит исходные строки к `PromoFact`. Обязательные поля: период, аптечная сеть, бренд, SKU и процент инвестиций/бонуса. Необязательные поля: фактически начисленный бонус в рублях и текстовая механика промо.

## Бизнес-правило

Процент инвестиций трактуется как фактически начисляемый бонус за продажи SKU в аптечной сети, а не как скидка покупателю. Сервис не вычисляет сумму бонуса без данных о продажах и не подменяет отсутствующую сумму нулём. Расчёт бонуса по ставке должен выполняться отдельным финансовым сервисом на основе продаж SKU в соответствующей сети и периода.

## Безопасность публикации

`PromoNormalizationService` отклоняет публикацию, если нет ни одной корректной строки. При успешной публикации факты, метаданные версии источника и инвалидация агрегатов фиксируются транзакцией IndexedDB. Fingerprint — механизм обнаружения изменений, не криптографическая подпись.
