# Итерация 35 — запись результатов сценариев с версией данных

Добавлен `ScenarioResultPersistenceService`. Он записывает результат сценария и его метаданные в одной read-write транзакции IndexedDB, читая активную версию проекта в рамках той же транзакции.

Каждая запись содержит `projectId`, `scenarioId`, `datasetVersion`, `algorithmVersion`, параметры, payload, статус и время создания. Для сохранения обязателен `expectedDatasetVersion`, полученный перед расчётом. Если активная версия поменялась во время вычисления, транзакция отменяется и вызывающей стороне предлагается повторить сценарий.

Добавлены unit-тесты проверки версии. Сервис пока не подключён автоматически ко всем старым исполнителям сценариев: вызывающие страницы должны передавать версию, на которой реально выполняли расчёт. Без установки зависимостей автоматические тесты и production-сборка не подтверждены.
