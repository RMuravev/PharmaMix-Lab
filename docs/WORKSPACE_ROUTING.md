# Изолированное рабочее пространство

Новая архитектура доступна по `/workspace`; классический интерфейс остаётся на `/`. Маршрут выбирается в `src/main.tsx`, а новый `WorkspaceApp` предоставляет независимую навигацию между Overview и импортом продаж.

## Проекты

Идентификатор проекта вводится в боковой панели и сохраняется как пользовательская настройка браузера. Это логическое разделение записей IndexedDB, не аутентификация и не механизм совместной работы. Для shared-workspace требуется backend и авторизация.

## Ограничения текущей итерации

- Маршрутизация намеренно лёгкая и не добавляет внешнюю библиотеку.
- Смена проекта влияет на следующие запросы страниц; данные не копируются между проектами.
- Импорт заменяет нормализованный набор продаж выбранного проекта после подтверждения.
- Нужны браузерные E2E-тесты и полный build/test на окружении с установленными зависимостями.
