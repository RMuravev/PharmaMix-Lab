# IndexedDB: схема и правила хранения

Имя БД сохраняется как `PharmaMixLabDB_v3`, версия схемы повышена до 2. Старые хранилища `sales`, `promos`, `tv`, `visits`, `market`, `meta` сохраняются для обратной совместимости. Миграция добавляет новые object stores и не удаляет существующие данные.

| Store | Назначение |
|---|---|
| `projects` | локальные проекты/рабочие пространства |
| `datasets` | версия и метаданные импортированных наборов |
| `importBatches` | история загрузок, проверки и статусы |
| `salesFacts` | факты аптечных продаж |
| `marketFacts` | продажи адресного рынка, своего и конкурентных брендов |
| `promoFacts` | промо-факты, включая механику и фактически начисленный бонус |
| `tvFacts` | TRP по бренду и периоду |
| `visitFacts` | взвешенные визиты медпредставителей |
| `dimensions` | нормализованные справочники измерений |
| `aggregates` | агрегаты для dashboard и страниц аналитики |
| `calculationJobs` | очередь и состояние расчётов |
| `modelRuns` | параметры, версии, статус и диагностика запуска модели |
| `modelResults` | результаты моделей, разделённые на типизированные записи |
| `scenarioResults` | результаты сценариев и оптимизации бюджета |
| `appMeta` | версии схемы, настройки и служебные метаданные |

Все новые записи должны иметь стабильный `id`, `schemaVersion`, `createdAt`; данные проекта — `projectId`. Для фактов сохраняются ссылка на импорт и версия набора. Промо-бонус — это начисление за продажи, а не скидка: его база и бизнес-смысл не должны переопределяться UI.

## Транзакции и производительность

- Не использовать `setTimeout`/таймеры внутри незавершённой IndexedDB-транзакции.
- Подтверждать успешную запись только по `transaction.oncomplete`, ошибки — по `onerror`/`onabort`.
- Импортировать связанные разделы в одной транзакции или через staging-набор с атомарной публикацией версии.
- Для счётчиков использовать `count()`, а не загружать все строки.
- Большие списки читать страницами/курсором; не вызывать `getAll()` из общих экранов без явного ограничения.
- IndexedDB — локальная база конкретного браузера, не общая база для нескольких пользователей.
