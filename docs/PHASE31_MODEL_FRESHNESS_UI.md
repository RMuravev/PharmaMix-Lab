# Phase 31 — UI контроля актуальности моделей

## Назначение

Экран `/workspace#models` предоставляет единое место для просмотра истории `modelRuns` и связанных `modelResults` проекта. Статус запуска сравнивает `datasetVersion` запуска с `projects.activeDatasetVersion`.

## Статусы

- `fresh`: версия запуска совпадает с активной версией набора.
- `stale`: активная версия отличается от версии запуска.
- `legacy`: версия набора не записана у запуска.
- `unverifiable`: у проекта нет активной версии для сравнения.

Если версия одного или нескольких `modelResults` отличается от версии запуска, интерфейс показывает дополнительное предупреждение.

## Ограничения

Это экран наблюдаемости, а не блокировка исполнения или выдачи результатов. Старые страницы приложения пока не обязаны использовать этот статус. Пустой список не означает, что модели не рассчитывались: это означает, что в `modelRuns` нет читаемых записей для текущего `projectId`. Подключение записи запусков и принудительное скрытие устаревших результатов остаются следующими этапами.
