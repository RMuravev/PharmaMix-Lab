# UI импорта продаж

Компонент: `src/pages/SalesImportPage.tsx`.

1. Пользователь выбирает CSV.
2. Парсер проверяет структуру CSV и показывает первые пять строк.
3. Пользователь явно подтверждает замену нормализованного набора продаж текущего проекта.
4. `SalesNormalizationService` нормализует строки и атомарно обновляет `salesFacts`, `datasets` и инвалидацию агрегатов.
5. UI показывает импортированные/пропущенные строки, версию данных и диагностические сообщения.

Ожидаемые заголовки поддерживаются через алиасы в `salesNormalizer.ts`; рекомендуемые поля: `год-месяц`, `регион`, `город`, `аптечная сеть`, `бренд`, `SKU`, `продажи в штуках`, `продажи в рублях`.

Компонент намеренно не подключён к старому DOM-навигационному роутеру автоматически. До интеграции нужно проверить пользовательский сценарий в поддерживаемых браузерах и добавить явный маршрут/feature flag.
