# Overview — новая изолированная страница

`src/pages/OverviewPage.tsx` — первый UI-компонент новой архитектуры, который обращается к данным только через `OverviewQueryService`. Компонент содержит состояния загрузки, ошибки и готовых данных; KPI не вычисляются в React-компоненте. Стили вынесены в отдельный файл и используют CSS custom properties с безопасными fallback-значениями.

## Подключение

Страница подготовлена как самостоятельный компонент, чтобы не вмешиваться в DOM-инициализацию legacy-приложения (`initPharmaMixApp`) до появления маршрутизатора. Следующий этап — добавить route `/overview-v2`, обеспечить выбор существующего `projectId` и провести browser integration tests. До этого она намеренно не заменяет текущий Overview.

## Проверка данных

Для отображения необходимы `salesFacts` и опубликованная запись `datasets` с `sourceType: sales` для проекта. При отсутствии нормализованных фактов показывается понятная ошибка и кнопка повторной загрузки. Для аудита отображаются версия набора данных и версия алгоритма агрегирования.
