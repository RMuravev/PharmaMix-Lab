# Нормализация продаж

`normalizeSalesRows(rows, projectId)` — чистая функция преобразования импортированных строк в `SalesFact[]`. Она принимает алиасы колонок на русском и английском языке и возвращает нормализованные факты, список ошибок по исходным номерам строк, количество пропусков и fingerprint.

`SalesNormalizationService.normalizeAndCommit({ projectId, rows, sourceBatchId })` атомарно заменяет нормализованные продажи только указанного проекта, записывает новую версию источника и инвалидирует агрегаты в той же транзакции. При отсутствии валидных строк транзакция не запускается, прежний набор остаётся доступным.

## Ожидаемые поля

- Период: `YYYY-MM` или `YYYY-M`.
- Бренд и SKU: обязательны.
- Продажи в штуках и рублях: конечные неотрицательные числа; для русской локали допускаются запятая и пробелы-разделители разрядов.
- Регион и аптечная сеть могут отсутствовать, в таком случае записывается значение «Не указан/Не указана».

## Важное

Fingerprint нужен для определения изменений данных и не является криптографической гарантией уникальности. Сервис не удаляет legacy-данные из `sales`; удаление старого хранилища возможно только после миграции UI и проверки восстановления.
