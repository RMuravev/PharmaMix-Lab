# Итерация 39: диагностика OOS-моделей

Экран временной валидации отображает сравнение моделей на общей выборке прогнозов. Для каждой строки берутся только наблюдения, у которых `actual` и прогнозы всех моделей конечны. Это важно, например, для наивного прогноза, у которого может не быть доступной истории для части наблюдений.

Метрики: MAE, RMSE, WAPE, MAPE и R². MAPE исключает нулевые фактические значения и сообщает число исключённых наблюдений в диагностическом сервисе; WAPE не определяется, если сумма абсолютных фактических значений равна нулю. В таблице неопределённые значения показываются как «—».

Ранжирование: меньший WAPE лучше; если WAPE не определён, используется RMSE. Сравнение справедливо только для одного test window и одинакового упорядоченного вектора фактических значений.

Ограничения: метрики не являются тестом статистической значимости и не подтверждают причинность. Текущая реализация использует OOS-предсказания, сформированные существующим валидатором; архитектура формирования временных окон не изменялась.
